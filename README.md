# Assignment 3 — Interactive To-Do List App

**Student:** Alfred Habre  
**Course:** Web Development

## Features
- Add a new task
- Press Enter to add a task
- Mark a task complete or incomplete
- Delete a task
- Reject empty or whitespace-only tasks
- Save tasks with localStorage
- Reload saved tasks after refreshing the page
- Update the list dynamically without reloading the page

## Technical Requirements
- HTML, CSS, and vanilla JavaScript only
- Uses named JavaScript functions
- Uses `map()` and `filter()` array methods
- Tasks are rendered from a JavaScript array

## How to Run
1. Extract the ZIP file.
2. Open `index.html` in a browser.
3. Add, complete, and delete tasks.
4. Refresh the page to verify localStorage persistence.
